# 给上游的改动说明（安卓 ECH 分支）

这个分支在上游基础上只做一件事：**让安卓端在受限网络下能正常用**——受保护域名不被 SNI 阻断、
不被污染 IP 带偏；拿不到 ECH 配置就失败，绝不回落明文。分支 `ech-conscrypt`，相对上游 60 余个提交（数字随每次提交变化，不必逐次同步）。

## 1. 传输层（原生请求）

- Ktor 的 OkHttp 引擎统一安装 `BgmEchTransport`：受保护域名的地址**只来自自有 DoH**，
  TLS 走 Conscrypt 并携带 ECHConfigList；上游业务插件、Cookie、认证逻辑未改动。
- `BgmEchPolicy.PolicyTrustManager` 必须保留带主机名的 `checkServerTrusted` 入口：
  系统在启用域名级网络配置时会直接抛 `Domain specific configurations require that hostname aware
  checkServerTrusted(X509Certificate[], String, String) is used`（已实测复现并修复）。

## 2. WebView

- `EchWebViewClient`：受保护域名的 **GET/HEAD** 由原生代发；GET 失败返回 502 页面，
  绝不返回 `null` 放行（返回 null 等于交回 WebView 自己的明文栈）。
- `EchWebBridge` + 注入脚本：`fetch`/XHR/表单等非 GET 交原生代发。桥在原生侧**复核**目标域名、
  **发起页面**、方法白名单与体积上限；Cookie 与 `CookieManager` 共用一份，登录态不分叉。
- 四个 WebView 宿主（内置浏览器、人机验证、工作流弹窗、Pixiv 登录）都传了
  `platformWebViewParams` 与自定义 factory。

## 3. DoH

- 网关池由 `ECH_DOH_POOL` 在构建期注入（格式 `https://网关/dns-query|ip1|ip2`），**源码不含任何网关地址**。
- **ECH 活值优先走国内三家纯 IP**（阿里 `223.5.5.5`/`223.6.6.6`、腾讯 `1.12.12.12`/`120.53.53.53`、
  360 `101.198.193.29`/`101.198.192.33`）：纯 IP + wire（`Accept: application/dns-message`，
  **绝不带 `Host` 头**），随机挑一家、单家 2.5 秒超时、失败换下一家；三家都不通才回落上面的网关链路。
  好处是不查系统 DNS、不被污染、证书直接对 IP 有效，还少一跳。实测六家都返回同一份 71 字节配置。
- 活值同时解析 SVCB 的 `key=5`（ech，**自带 2 字节长度前缀**，可直接喂 Conscrypt）与
  `key=4`（ipv4hint），并落盘到 SharedPreferences `ech_state`（有效期 ≤5 小时）；
  `Application` 启动即挂载落盘仓并预热，**在任何 native 库加载之前**，不等第一个客户端。
- 按主机加锁合并并发；失败先换端点重试一次，仍失败才写 5 分钟冷却（持久化，重启不绕过）；
  网络失败时用最近一次成功的地址/配置兜底——最坏是握手失败，不会明文回落。
- 启动即预热常用域名（API、图源、人机验证域）。

## 4. 上游两个具体问题的修复

- **资源压缩会删掉运行时按名读取的资源**：网关地址用 `resources.getIdentifier("ech_doh_pool", …)` 读，
  没有 `R.string` 引用，`isShrinkResources = true` 会连名带值一起删掉，正式包装上后所有受保护域名
  静默阻断。已在 `android/src/main/res/raw/keep.xml` 加 `tools:keep`，并在 CI 里对产物
  `resources.arsc` 做断言（只比对资源名不够，值被替换同样会坏）。
- **图源搜索词过滤**：原实现会连日文汉字原名一起过滤，anime-pictures 任何角色都返回 0 条；
  已改为原名无条件保留，别名仅在原名缺失时退回。

## 5. 构建与门禁

- 独立包名 `com.anglesgirl.bangumi.ech`（可与原版共存），Firebase 用独立工程。
- `ech-android.yml`：debug + release 双包、私有 Release 存产物、产物级断言、
  诊断日志上传失败不阻断测试包。
- `tools/check_*.py` 六道静态门禁 + 注入脚本离线断言（node），全部在编译前跑；
  其中传输层门禁 43 条断言覆盖 ECH 取数标准（三家 IP、随机换家、只认 wire、落盘/丢弃、启动挂载）。

## 6. 验证边界（合并前请留意）

- 本分支的 CI **只编安卓**；iOS/jvm 的 `actual` 已补齐，但**未在 CI 中编译验证**。
- WebView 中受保护页面的**第三方子框架**仍可调用传输桥（已知残留面，未再细化）。
- 子请求依赖 `shouldInterceptRequest`；WebSocket/Worker 不走它，已由 loopback 代理侧
  **拒绝受保护域名**兜底（宁可失败，不放明文）。
- 真机（小米 2604FRK1EC / Android 16）实测：bgm、pixiv、图源、人机验证全部可用；
  冷启动偶发失败已通过"先重试、再用最近成功的地址兜底"处理。
